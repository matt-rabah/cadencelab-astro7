# Platform logos

Place the approved SVG wordmarks for the homepage platform rail in this folder using these exact lowercase filenames:

- `salesforce.svg`
- `hubspot.svg`
- `zendesk.svg`
- `gainsight.svg`
- `qualtrics.svg`
- `servicenow.svg`

Keep each SVG's `viewBox`, remove unnecessary editor metadata, and do not embed
raster images, scripts, external resources, or fixed background rectangles.
The homepage shows the platform name as a fallback until its matching SVG is present.
